Why 0.1563 Repeats — Two Independent Causes

Cause 1 — our own byte-identical duplicates (audited 2026-09-26):

  • GEMSDOE1 and 5GEMSDOE ship identical docs/submission_field.bin SHA256 b966d47c7c02b1c2… (532,072 B, 259,495 runs) → submission.tif SHA256 7f00890a62878d61… 172,974 px at 1.0. Identical bytes ⇒ identical DTI.
  • GEMSDOE2 recall arm shipped the same bytes again — triple duplicate.
  • Fix in this repo: builder generates unique UTC + SHA8 and refuses to publish any artifact whose SHA matches a known duplicate (scripts/build_site.py, tests/test_validation.py::test_no_duplicate_sha).

Cause 2 — the catalogue attractor (observed 2026-09-27 on the live leaderboard): three unrelated-looking accounts at exactly 0.1563 with only 2 submissions each. DrivenData staff confirmed known-catalogue pixels are masked from scoring (forum thread 11516), so any submission that mostly re-emits the provided catalogue scores only through haloes within 300 m of withheld faults — and that evidently saturates at ≈0.1563. Beating it requires predicting faults that are not in the catalogue. See Official Intel and Strategy.

How to Beat 0.3049 — Distinct Strategy

Gap +0.1486 requires a genuinely better detector of unmapped traces, not a better fitting proxy.

  • Previous best 0.1563 used a 12-fold ensemble, floor 0.1, skeleton width 0 — thinned skeleton at floor 0.1, width curve peaks at 0 px on every ensemble (GEMSDOE1 width measurement).
  • 6GEMSDOE 0.0286 used HGB 88ch top 3% — catalogue-memorising signature, lowest public score, highest proxy 0.1527 — proxy contaminated.
  • 8GEMSDOE measurement: in-file features alone at or below random for the real task, but adding external channels beats random — base+structural-coherence 0.0895 vs random 0.0813 on Fold0 at 3% budget — first to beat random on unseen traces.
  • H9-1 relay stepover + dilation tendency targets the interaction settings that dominate Great Basin geothermal (stepovers ~32%, terminations ~25%, intersections ~22% of 250+ catalogued fields — GDR 383, details in Research) — faults missing from the catalogue, strong strain signal.
  • Union strategy: catalogue trace included free of FP cost (staff-confirmed masking) + H9 hypotheses on top. Floor is preserved; upside is open.
